## Working Memory

<!-- Key context: file paths, patterns, naming conventions, gotchas.
     Updated during plan and apply. Keep under 100 lines. -->

- Package: root is `Main.kt` (no package), audio in `audio/`, ui in `ui/`
- Entry: `fun main() = application { Window { ... } }`
- Audio format: 44100 Hz, 16-bit PCM, mono, little-endian
- FFT: JTransforms `DoubleFFT_1D(1024)`, output 512 magnitude bins
- Gradle: `kotlin("jvm")` + `org.jetbrains.compose`, single module
- Data flow: AudioSource(StateFlow) → FFTProcessor(StateFlow) → SmoothedMagnitudes → Visualizer(composable)
- Threading: IO for audio read, Default for FFT, Main for UI
- New files phase 3: audio/AudioSource.kt (interface), audio/FileAudioSource.kt
- AudioSource interface: samples, gain, pause(), resume(), stop()
- FileAudioSource: two-step decode (compressed→PCM→target), read-and-tee, @Volatile paused flag
- SourceMode enum in ui/ControlBar.kt (MIC, FILE)
- MP3 SPI needs full AudioFormat for decode, not just Encoding
- Device enum: AudioSystem.getMixerInfo() → filter TargetDataLine → mixer.getLine()
- Gain: float multiplier in AudioCapture.bytesToFloats(), range 0-5x
- Theme colors: primary=#7B61FF, surface=#1A1A1A, background=#0D0D0D
- Visualizers: SpectrumVisualizer (bars), WaveformVisualizer (path+gradient), CircularVisualizer (radial lines)
- VisualizationMode enum in ui/VisualizationMode.kt (BARS, WAVEFORM, CIRCULAR, PARTICLES, KALEIDOSCOPE, TRAILS)
- SmoothedMagnitudes: max(current, prev - decayRate * decayMultiplier) decay per frame
- BeatDetector: update() accepts thresholdMultiplier param
- VisualizerConfig sealed class in ui/VisualizerConfig.kt — per-visualizer config data classes
- ReactivityConfig in audio/ReactivityConfig.kt — band sensitivity, beat threshold, smoothing
- kotlinx.serialization added to Gradle (plugin + kotlinx-serialization-json:1.8.0)
- Presets dir: ~/.audio-visuals/presets/ (JSON files)
- VisualizerLayer: id, vizMode, config, opacity, blendMode, enabled — multi-layer rendering via Box stacking
- LayerBlendMode: serializable enum wrapping Compose BlendMode (Normal, Screen, Lighten, Multiply, Overlay, Difference, ColorDodge, Plus)
- Layer rendering: layers.forEach with graphicsLayer { alpha; CompositingStrategy.Offscreen }
- SettingsPanel: layer-centric — layer list with add/remove/reorder, selected layer config, global reactivity
- ControlBar: VizModeToggle removed, replaced with layer summary indicator
- Preset format: multi-layer (layers array), auto-migrates old single-mode format on load
- OpenSimplex2: audio/OpenSimplex2.kt — noise3_ImproveXY(seed, x, y, z) returns [-1,1]
- FlowFieldVisualizer: ui/FlowFieldVisualizer.kt — 3000 particles, noise-driven flow, line segment trails
- FlowFieldConfig: @SerialName("flow_field") — noiseScale, fieldSpeed, particleDrag, particleSpeed, trailLength, beatTimeJump, turbulenceMin/Max
- VisualizationMode: FLOW_FIELD added as 8th mode, TERRAIN as 9th
- TerrainVisualizer: ui/TerrainVisualizer.kt — 40×30 grid, perspective projection, noise+magnitude height, distance fog
- TerrainConfig: @SerialName("terrain") — gridCols, gridRows, heightScale, noiseScale, scrollSpeed, focalLength, cameraTilt, fogStart, fogEnd
- CurvesVisualizer: ui/CurvesVisualizer.kt — 3 modes (Lissajous, Rose, Spirograph), trail fade, musical intervals
- CurvesConfig: @SerialName("curves") — curveMode, pointCount, lineWidth, trailAlpha, speedMultiplier, colorCycleSpeed
- CurveMode enum: LISSAJOUS, ROSE, SPIROGRAPH — in VisualizerConfig.kt
- VisualizationMode: CURVES added as 10th mode
